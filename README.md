# CKEditor Accordion

Provides a CKEditor plugin that allows users to create & display content in an accordion.

## Installation

- Install this module using the official [Backdrop CMS instructions](https://backdropcms.org/guide/modules)
- Enable the plugin for the text formats of your choice

## Issues

Bugs and Feature requests should be reported in the [Issue Queue](https://github.com/backdrop-contrib/ckeditor_accordion/issues)

## Known issues

CKEditor 4 has reached end of life back in June 2023.

Its successor CKEditor 5 is a substantially different piece of software.
That's why providing something equivalent for v5 is quite tricky. See
[this issue for details](https://github.com/backdrop-contrib/ckeditor_accordion/issues/9).

If you're willing to help with that task, you could apply to take over
maintainership of this module, or provide a pull request. Or both. ;-)

If you *urgently* need this functionality with an up to date and supported
editor, and you're open for alternatives, take a look at this
[TinyMCE plugin](https://backdropcms.org/project/tinymce_js_accordion) instead.
